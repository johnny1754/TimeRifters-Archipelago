Time Rifters Archipelago bundles the unmodified BepInEx 5.4.23.2 Windows x86 runtime
with a Time Rifters-specific configuration file and this mod's plugin DLL.

BepInEx is licensed under the GNU Lesser General Public License, version 2.1.
Its source code and license are available from the official project:
https://github.com/BepInEx/BepInEx/tree/v5.4.23.2

The BepInEx runtime files are not modified. The included BepInEx.cfg is a separate
configuration file that selects the compatible Unity 4.5.5 startup entry point.
