BepInEx 5.4.23.2 Windows x86
----------------------------
The complete setup package bundles the unmodified BepInEx 5.4.23.2 Windows x86
runtime with a Time Rifters-specific configuration file and this mod's plugin DLL.

The BepInEx v5.4.23.2 tag is distributed under the MIT License. A copy of that
license is included in LICENSES/BepInEx-MIT.txt.

Official source for the bundled version:
https://github.com/BepInEx/BepInEx/tree/v5.4.23.2

The BepInEx runtime files are not modified. The included BepInEx.cfg is a
separate Time Rifters compatibility configuration that selects the compatible
Unity 4.5.5 startup entry point.
